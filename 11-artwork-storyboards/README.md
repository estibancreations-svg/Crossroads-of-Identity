# Crossroads of Identity — Artwork & Storyboards

This directory indexes screen-development artwork and storyboards while binary masters remain in Google Drive.

Drive folder: https://drive.google.com/drive/folders/1uNfxwSuEgVqxQPSVOoa9yqBzqbbmXIMw

## Rule
Every future visual asset should be labeled with its source class:
- `MANUSCRIPT_DERIVED`
- `CHARACTER_HISTORY_DERIVED`
- `ADAPTATION_R&D`
- `VISIONWEAVER_GENERATED`

No generated visual should silently redefine manuscript character identity, setting, chronology or relationship continuity.
