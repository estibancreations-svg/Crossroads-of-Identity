# Crossroads of Identity — VisionWeaver World Model Integration

**Date:** 2026-10-03

Crossroads production should consume VisionWeaver's persistent world-state architecture for future scene generation and continuation.

Production continuity should preserve:
- character identity and physical state
- wardrobe/prop continuity
- room/location geometry
- off-screen sound sources
- lighting and weather state
- camera position/orientation
- environmental physics
- temporal state
- uncertainty/confidence
- prior causal events

Camera changes should reveal the same established location rather than regenerate unrelated geography.

The canonical implementation belongs in VisionWeaver; this file is a project-level integration requirement, not a duplicate engine specification.
